# mybudget

* A simple budgeting app for managing personal finances.
* Single-page HTML5 page

# Features

* Track income and expenses
* Categorize transactions
* Visualize spending with charts and graphs
* Export data to CSV or PDF
* Set budget goals and track progress
* Responsive design for mobile and desktop

# Design

* Clean and intuitive user interface
* Use of modern web technologies (HTML5, CSS3, JavaScript)
* Local storage for data persistence
